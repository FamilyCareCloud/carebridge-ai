# CareBridge 번역 품질 평가 v1

## 평가 범위와 판정 방법

이 평가는 현재 서비스 중인 로컬 GPU 번역 경로에 실제 요청을 보내 수행한다.
영어·베트남어·인도네시아어의 짧은 합성 관찰 메모 36건과 QA 대조군 36건을 사용한다.
실제 대상자 정보는 사용하지 않는다. 음성 인식, 다른 언어, 긴 문서, 사용자 사용성은 범위 밖이다.

`evaluation/translation-corpus-v1.json`의 원문, 한국어 기준문, 필수 의미 목록,
오역 주입 항목을 실행 전에 고정했다. 실행 결과에는 이 파일의 SHA-256을 기록한다.
기준문과 검토는 AI가 작성했다. 독립된 원어민 전문가의 맹검 평가나 임상 검증을 대신하지 않는다.

번역은 HTTP 성공이나 서비스 모델의 자체 검사 결과로 정확하다고 판정하지 않는다.
각 출력과 사전에 적은 필수 의미를 별도로 대조한다.
정답 문구와 다르더라도 의미가 같으면 허용하며, 표현이 같아도 부정의 대상,
발언 주체, 시각, 단위 등이 달라지면 오류로 본다.

번역 판정:

- `clean`: 필수 사실·부정·추측·수치·시간·발언 출처를 보존하고 한국어가 자연스럽다.
- `minor`: 의미는 보존하지만 한국어가 어색하거나 문법·표기에 사소한 문제가 있다.
- `major`: 필요한 사실/출처 누락 또는 사실 추가 등 의미가 달라졌다.
- `critical`: 긍정·부정 반전, 추측의 단정, 양·단위·시간 변경 등 핵심 관찰이 왜곡됐다.
- `unavailable`: 유효한 번역 응답을 얻지 못했다.

`clean`과 `minor`만 이 문장 집합에서의 의미 보존으로 집계한다.
분류 및 확인 질문 생성은 번역 정확도와 구분해 검토한다.
이 결과로 모집단 번역 정확도나 서비스 전체의 안전성을 추정하지 않는다.

QA 평가는 번역 성적과 별개다. 한국어 기준문을 넣은 충실한 대조군 9건과,
부정/추측 삭제, 수치/단위/시각 변경, 사실 추가/누락, 발언을 관찰로 변경,
부정 범위 반전의 오역 27건을 API에 보낸다.
오역이 `hold`가 되면 차단, `review_required`가 되면 놓침이다.
충실한 기준문이 `hold`가 되면 오탐으로 집계한다.
요청 실패는 차단 성공으로 세지 않는다.
`model_checked=false`는 앞선 구조·어휘 검사에서 보류해 모델 검사를 생략했다는 뜻이다.
`review_required`도 사람 검토가 필요하며 승인·자동 공유 상태가 아니다.

## 재현

GPU 서비스가 이미 실행 중인 저장소 루트에서:

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_translation.py
```

서비스를 추가로 띄우거나 모델을 다시 로드하지 않는다.
키는 환경변수 또는 무시되는 로컬 `.env`에서 읽고 결과에 기록하지 않는다.
요청은 순서대로 보낸다. 도중 중단된 실행은 같은 기준 파일로 `--resume`할 수 있다.
완료한 결과를 보관하려면 다른 `--output` 파일명을 지정한다. 종료코드 0은 요청과 QA 대조군의 기대 상태가 맞았다는 뜻이며, 번역 의미의 품질 합격을 뜻하지 않는다.

## 2026-10-27 실행 결과

판정: **번역과 QA의 품질 개선이 필요하다.**
기능이 동작한다는 것과 번역 의미가 정확하다는 것은 별개이며,
현재 모델의 자체 재검사만으로 품질을 보증할 수 없다.

실행 중인 CUDA 서비스에서 기본 평가 72개 요청(번역 36 + QA 36)을 순서대로 보냈다.
발견된 문제 중 6건을 나중에 다시 요청했고, 같은 번역·보류 상태 또는 같은 502 실패가 재현됐다.
재실행은 문제를 본 뒤 고른 사례이므로 별도의 독립 평가 성적으로 합산하지 않는다.

환경: RTX 5070 Ti, 배포 설정의 `unsloth/Qwen3-8B-unsloth-bnb-4bit`,
로컬 번역과 의미 재검사 활성화. 별도 GPU 모델을 로드하지 않고 기존 서버를 평가했다.
평가 범위는 텍스트 입력이다.

### 번역 자체: 기준문 대비 AI 검토

| 언어 | 문장 | clean | minor | major | 생성 실패 | 의미 보존으로 검토한 건 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 영어 | 12 | 11 | 1 | 0 | 0 | 12 |
| 베트남어 | 12 | 7 | 3 | 1 | 1 | 10 |
| 인도네시아어 | 12 | 6 | 1 | 4 | 1 | 7 |
| 합계 | 36 | 24 | 5 | 5 | 2 | 29 |

이는 **작은 합성 집합에 대한 AI 대조 결과**다. 일반 번역 정확도나 원어민 전문가의
판정으로 해석하면 안 된다. `id-ambiguity`는 한국어가 모호해 보존을 확정하지 않은
보수적 major 판정이며, 나머지 명확한 의미 오류와 구분해 아래에 적었다.

주요 사례:

| ID | 원문 핵심 의미 | 실제 출력 | 판정 |
| --- | --- | --- | --- |
| vi-ambiguity | Có vẻ mệt. Không rõ lý do. → 피곤해 보임, 이유 불명 | 어색해 보인다. 이유가 분명하지 않다. | 피곤함을 어색함으로 변경. 재검사에서도 보류하지 않음 |
| id-uncertainty | Mungkin sudah tidur setelah makan siang. → 점심 후 잠을 잤을 수도 있음 | 점심을 먹은 후 아마도 잠을 자 perhaps. | 미완성 한국어·영어 잔존, 완료된 수면의 가능성을 온전히 전달하지 못함. 보류됨 |
| id-assistance | Berjalan ke kamar mandi dengan bantuan. → 도움을 받아 화장실까지 걸어감 | 화장실로 가기 위해 도움을 받았습니다. | 보행과 이동한 사실이 목적 표현으로 바뀜. 보류하지 않음 |
| id-contrast | Minum air tetapi tidak makan sup. → 물은 마셨지만 수프는 먹지 않음 | 물은 마시지만 식사하지 않음. | 수프를 식사 전체로 일반화. 보류하지 않음 |
| id-ambiguity | Tampak lelah. Alasannya tidak diketahui. → 피곤해 보임, 이유 불명 | 피로 보입니다. 이유는 알려져 있지 않습니다. | 온전하고 명확한 한국어로 피곤함을 전달했다고 확정할 수 없어 수정 필요. 보류하지 않음 |
| vi-chronology | 점심 후 30분 수면, 15:00 기상 | HTTP 502 | 한국어 번역 검사를 통과하지 못해 유효한 번역 없음 |
| id-medication | 20:00에 아직 약을 복용하지 않음 | HTTP 502 | 한국어 번역 검사를 통과하지 못해 유효한 번역 없음 |

그 밖에 `수면이 있었을 수 있습니다`, `정오 식사`, `위생실`,
`점심 식사 반량으로 먹음 / 오늘은外出하지 않음` 등 부자연스러운 표현이 있었다.
수면을 `other`로 분류하는 사례도 확인했다. 각 문장별 판단과 부수 문제는
[번역 검토 기록](../evaluation/translation-review-v1.json)에 남겼다.

### 생성된 번역을 검사한 결과

- 유효한 번역 응답: **34/36**, 생성 실패 **2/36**.
- 반환된 34건 모두 원문 해시·구간 인용 검사를 통과했고, 사람 검토 필수·외부 공유 불허 상태였다.
  이 검사는 의미 정확도를 증명하지 않는다.
- 서비스가 반환한 보류는 **7건**이었다. 기준문 대조에서 올바르거나 사소한 표현 문제인
  번역을 보류한 **6건**, major 출력을 보류한 **1건**으로 나뉜다.
- major 판정 5건 중 **4건은 보류되지 않고 review_required**였다.
  review_required는 승인 상태가 아니며, 여전히 사람이 원문과 대조해야 한다.
- 번역+설정된 재검사의 응답 시간은 성공 응답 기준 약 **4.1초**가 중앙 수준,
  최장 **7.144초**였다. 작은 순차 평가이며 동시 처리량 성적이 아니다.

오탐 예:

| ID | 실제 번역 | 보류 이유 | 기준문 대조 |
| --- | --- | --- | --- |
| en-chronology / id-chronology | 15:00을 오후 3시로 번역 | NUMERIC_FACTS_PRESERVED | 같은 시각인데 원시 숫자 토큰 비교가 실패함 |
| en-ambiguity | 피곤해 보였지만, 이유는 알려지지 않았습니다. | NEGATION_SIGNAL_PRESERVED | unknown과 알려지지 않음을 제한된 어휘 신호로 대조하지 못함 |
| en-multiline | 점심 반만 먹었습니다. / 오늘 외부로 나가지 않았습니다. | SEMANTIC_NEGATION / SEMANTIC_UNCERTAINTY | 원문의 식사·외출 사실이 보존됐는데 모델 재검사가 보류함 |
| id-reported_speech | 오늘은 통증이 없다고 말했습니다. | SEMANTIC_UNCERTAINTY | 발언 출처가 보존됐는데 모델 재검사가 보류함 |
| id-multiline | 점심 식사 반량으로 먹음 / 오늘은外出하지 않음 | SEMANTIC_NEGATION / SEMANTIC_UNCERTAINTY | 표현은 수정해야 하지만 두 사실의 긍정·부정은 보존됨 |

### 고정한 QA 대조군

충실한 한국어 기준문 9건은 모두 `review_required`였고 보류 오탐은 없었다.
이것은 위에서 모델이 실제 생성한 다양한 표현에서 나온 오탐 6건과 다른 집합이다.

| 의도적으로 넣은 오류 | 사례 | 보류 | 놓침 |
| --- | ---: | ---: | ---: |
| 부정 삭제 | 3 | 3 | 0 |
| 추측 삭제 | 3 | 3 | 0 |
| 150 → 500 수치 변경 | 3 | 3 | 0 |
| mL → L 단위 변경 | 3 | 3 | 0 |
| 14:30 → 04:30 시각 변경 | 3 | 3 | 0 |
| 가족에게 전화했다는 행동 추가 | 3 | 3 | 0 |
| 도움을 받았다는 사실 누락 | 3 | 0 | 3 |
| 당사자의 발언을 확인된 관찰로 변경 | 3 | 3 | 0 |
| 부정의 대상을 물·수프 사이에서 반전 | 3 | 3 | 0 |
| 합계 | 27 | 24 | 3 |

누락 사례의 원문은 언어마다 “도움을 받아 화장실까지 걸어갔다”이고,
주입한 한국어는 “화장실까지 걸어갔습니다.”였다. 세 언어 모두 재검사에서
사실 누락을 보류하지 않았다. 숫자·부정·추측 변경 12건은 모델 앞의 검사에서 보류했고,
나머지는 모델이 재검사했다. 보류된 사례도 오류 코드가 실제 원인을 정확하게 설명한다고
단정할 수 없다. 예를 들어 단위 변경에서 부정·추측 코드까지 함께 실패했다.

### 다음 개선 우선순위

1. 베트남어의 상태 단어와 인도네시아어의 동작·대상·완료 여부를 보존하도록 번역을 개선한다.
   문장이 불완전하거나 불필요한 다른 언어가 섞인 출력도 검출해야 한다.
2. 사실 추가뿐 아니라 **필수 사실 누락**, 행동의 완료/목적, 발언 출처의 변경도 재검사 항목에 포함한다.
3. 동등한 시각·단위 표기를 정규화하고 부정·추측의 범위를 개선해 오탐을 줄인다.
   단순한 단어 존재 여부나 숫자 토큰 일치는 의미 검사를 대신할 수 없다.
4. 이 고정 집합을 회귀 점검에 보존하되, 개선 후에는 겹치지 않는 문장과 원어민 검토자를
   이용해 다시 검증한다. 현재 결과만으로 자동 승인·공유 범위를 넓히지 않는다.

이번 작업은 평가와 근거 기록이다. 번역 모델을 학습하거나 서비스 코드를 수정해
문제를 해결했다고 보고하지 않는다.
